# Python Calculator

A simple calculator program written in Python.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero

## Technologies Used
- Python 3

## How to Run

1. Download the project.
2. Open a terminal.
3. Run:

```bash
python Calculator.py
```
